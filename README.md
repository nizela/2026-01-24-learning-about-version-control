# Learning about Version Control

**Author:** Nizel Abalos

Solving merge conflicts takes conscious effort, but I can do it!

**What I like most about version control:** What I like the most about version control is that it provides me with the history of my work and the work of other collaborators, making it easy to go to previous versions and see how a project evolves over time. It also provides me with an organized way of keeping track of what changes were made and why based on committed changes and comments.

**What I find most challenging/confusing/frustrating about version control:** What I find the most challenging about version control is understanding and resolving merge conflicts, especially when it comes to remembering the correct sequence of commands to properly resolve the conflict. Another thing that I find confusing about version control is managing different branches and understanding where the changes are made and ensuring that the changes are being merged into the main branch correctly.
